# Classifier_vehicle_image
Just following the instruction to download the correspond library, then run the ./main.py file found in the code folder.
To install the required libraries run following command
'''bash
pip install -r requirements.txt
'''
To run the pipeline run following command
'''python
python ./code/main.py
'''

Then you will get the result folder in the folder code, which has name equals to the timestamp that you run the pipeline
