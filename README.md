# Classifier_vehicle_image
Just following the instruction to download the correspond library, then run the ./main.py file found in the code folder.
To install the required libraries run following command
<pre>bash
pip install -r requirements.txt
</pre>
Then setup your prompt, and indicate your image dataset at "main.py", finally to run the pipeline run following command
<pre>python
python ./code/main.py
</pre>

Then you will get the result in a folder, which has name equals to the timestamp that you run the pipeline.
